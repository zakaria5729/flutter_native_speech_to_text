# flutter_native_speech_to_text Example App

A Flutter application demonstrating how to integrate and use the `flutter_native_speech_to_text` plugin with Android's native `ACTION_RECOGNIZE_SPEECH` Intent.

## Features Demonstrated

- Checking recognizer service availability (`FlutterNativeSpeechToText.isAvailable()`).
- Listening for speech input with custom prompt, language, and extra parameters.
- Displaying recognized text, alternative transcriptions, and confidence scores.
- Session stop and cancel actions.

## Getting Started

1. Open the project on an Android device or emulator with Google Play Services and Google Speech Recognizer installed.
2. Run:

```bash
flutter run
```
